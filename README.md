# Contact Web Form

A modern multi-step contact form built with React, Vite and Tailwind CSS.

## Live demo

The project is deployed at: https://contact-web-form.vercel.app/

## Local development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## External API

The form loads country data from the external REST Countries API:

- https://restcountries.com/

The country list is used in the first step of the form to populate the country selector.
